MobControl - 岛屿怪物生成控制

📅 2026-11-01   |   🏷️ 资源

给玩家一个面板，让他们自己决定岛上哪些怪物不许生成。开关状态存在每个岛自己身上（BentoBox 岛屿 metadata），重启服务器、甚至换数据库都不会丢。默认配置里只写了史莱姆：玩家点一下史莱姆图标，自己岛上就再也不刷史莱姆了。

点击下载该插件 查看源代码

前置插件

BentoBox 3.x，外加至少一个游戏模式（BSkyBlock / AcidIsland / CaveBlock 等）。

插件要放进 plugins/BentoBox/addons/ 目录，不是 plugins/ 根目录，BentoBox 只在自己启用时扫描 addons 文件夹。首次启动会生成 plugins/BentoBox/addons/MobControl/config.yml。

功能说明

面板里一个怪物一个刷怪蛋图标：绿色名字加附魔光晕表示允许生成（默认），红色名字没有光晕表示禁止生成。点一下立刻切换，图标原地刷新，面板不会关掉。

能切换哪些怪物由 config.yml 里的 mobs 列表决定，只有写进列表的怪物才会出现在面板里，默认只配了史莱姆。

开关状态保存在岛屿的 metaData 里，key 是 mobcontrol:怪物名。重启服务器、更换数据库、备份还原岛屿都不会丢，重新点开就恢复生成。

默认只拦自然生成。刷怪笼、刷怪蛋、史莱姆分裂和别的插件刷出来的怪都不受影响；把 spawn.only-natural 改成 false，才会把这个岛上该怪物的所有生成来源一起拦掉。

只有岛主和岛屿成员能改这个岛，带了 admin 权限的管理员可以开关任意岛的怪物。

插件命令与权限

玩家命令

命令描述
/is mob打开自己岛的怪物生成控制面板，挂在岛屿命令下面（/island mob 也行，别名 /is mobs）
/mobcontrol备用独立命令（别名 /mobs），方便控制台或没装游戏模式时用

管理员命令

命令描述
/mobcontrol带 mobcontrol.admin 权限时可以开关任意岛的怪物
/bentobox reload改完 config.yml 后重载，不需要重进世界

管理员命令需要 mobcontrol.admin 权限。

权限

权限默认作用
mobcontrol.use所有玩家用 /mobcontrol 打开面板
mobcontrol.adminOP用 /mobcontrol 开关任意岛的怪物
bskyblock.mobcontrol.use所有玩家用 /is mob 打开面板（每个游戏模式各注册一份，AcidIsland 就是 acidisland.mobcontrol.use）
bskyblock.mobcontrol.adminOP用 /is mob 开关任意岛的怪物

配置文件：

mobs:
  - SLIME
  # - ZOMBIE
  # - SKELETON
gui:
  title: '&8岛屿怪物生成控制'
  rows: 3
  allowed-lore: '&a当前状态: &2允许生成'
  blocked-lore: '&c当前状态: &4禁止生成'
  click-hint: '&7点击切换'
spawn:
  # true = 只拦自然生成（刷怪笼、刷怪蛋、史莱姆分裂、插件生成都不受影响）
  # false = 该怪物在这个岛上的所有生成来源都拦
  only-natural: true
messages:
  no-island: '&c你还没有岛屿。'
  not-your-island: '&c这不是你的岛屿，你没有权限修改。'
  no-mobs: '&c服务端没有配置任何可切换的怪物。'
  toggled-on: '&a[怪物控制] 已允许 &e%mob% &a在你的岛屿生成。'
  toggled-off: '&c[怪物控制] 已禁止 &e%mob% &c在你的岛屿生成。'

怪物名怎么写

直接填 Bukkit EntityType 的名字，SLIME、ZOMBIE、SKELETON、CREEPER、ENDERMAN、PHANTOM、WITCH 都可以，大小写都行。写错的名字会被跳过，并在控制台提示。

要加新怪物，往 mobs 列表里追加一项，执行 /bentobox reload 或重启服务器即可，玩家不用重进世界。

几个注意点

面板里只显示 mobs 里配置过的怪物。配置得越多，面板行数就要跟着调大（rows 支持 1~6 行）。

messages 里所有文本都支持 & 颜色码，%mob% 会被替换成怪物名。

重置岛屿后会得到一个全新的岛，metadata 也是新的，之前的开关不会继承过来。想保持默认关闭的话，要等玩家在新岛上再点一次。
