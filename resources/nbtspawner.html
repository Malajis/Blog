NbtSpawner - 带 NBT 的刷怪笼

📅 2026-11-01   |   🏷️ 资源

让玩家可以放置带 NBT 的刷怪笼（比如小白刷怪笼、刷僵尸加蜘蛛的混合刷怪笼），并且让刷怪笼在生存模式下用任意工具、甚至空手都能挖下来，掉落物还保留原来的 NBT。两个功能都可以在 config.yml 里单独开关。

点击下载该插件 查看源代码

前置说明

只支持 Paper 1.21.x（1.21.5 及以上），不兼容 Spigot 和纯 CraftBukkit。

原版有两个限制：刷怪笼的方块实体 NBT 在 onlyOpCanSetNbt 的黑名单里，普通玩家放下时 NBT 会被直接丢掉；刷怪笼本身也没有战利品表，所以生存模式挖掉永远什么都不掉。这个插件补的就是这两点。

功能说明

玩家手上拿着带 NBT 的刷怪笼放下后，方块实体真正保留这份 NBT：刷什么怪、生成延迟、生成范围、生成数量都不再需要 OP 或创造模式。

刷怪笼在生存模式下可以用任意工具挖掉并掉落刷怪笼本体。insta-break 设为 true 时一挖即碎，设为 false 保持原版挖掘速度。

挖下来的刷怪笼放回去还是原来那个刷怪笼，掉落物会保留 NBT（break.keep-nbt）。

经验掉落默认关闭。开启后按原版 15~44 点计算，而且不再要求用"正确工具"，但"放下再挖"可以无限刷经验，生存服别开。

所有开关都关掉之后就是完全的原版行为，插件不会干预任何方块。

怎么拿到带 NBT 的刷怪笼

创造模式和 OP 可以用命令直接拿，1.21 的组件写法是这样（下面这条是小白刷怪笼）：

/give @p spawner[block_entity_data={id:"minecraft:mob_spawner",SpawnData:{entity:{id:"minecraft:skeleton"}}}]

也可以直接从刷怪笼建筑里挖，开启 break.drop-spawner 后，掉落物会自动携带原地形刷怪笼的 NBT。

插件命令与权限

管理员命令

命令描述权限
/nbtspawner reload重新加载 config.ymlnbtspawner.admin
/nbtspawner selftest跑一遍"放置 → 挖掘 → 重新放置"的 NBT 往返自检nbtspawner.admin
/nbtspawner info查看当前开关状态和内部 API 是否可用nbtspawner.admin

管理员命令需要 nbtspawner.admin 权限，默认只有 OP 拥有。

nbtspawner.place：当 place.require-permission 设为 true 时，放置带 NBT 的刷怪笼需要该权限，默认所有人拥有。没有权限的玩家放置会被取消并提示，物品不会丢 NBT。

配置文件：

place:
  enabled: true              # 允许放置带 NBT 的刷怪笼
  require-permission: false  # 是否需要 nbtspawner.place 权限

break:
  enabled: true              # 是否让刷怪笼可以被挖掉并掉落
  insta-break: false         # true = 一挖即碎；false = 保持原版挖掘速度
  drop-spawner: true         # 是否掉落刷怪笼本体
  keep-nbt: true             # 掉落物是否保留 NBT
  drop-exp: false            # 是否掉落经验（15~44），开了就能放下→挖掉无限刷经验

debug:
  self-test: false           # 启动时自动跑一次自检并打印往返结果
  self-test-shutdown: true   # 自检结束后自动关闭服务器（自动化测试用）

自检（排查问题用）

把 debug.self-test 设为 true 后重启，控制台会打印完整的往返结果，全部通过时末尾是 ===== 结果: PASS =====。

自检只会在出生点旁边 256 格、y 约 100~240 的空地上临时放一个刷怪笼，结束后立刻复原成原来的方块。不想反复自检的话，记得改回 false。

几个注意点

经验开关默认是关的，这是故意的：开了之后玩家可以放下再挖无限刷经验，生存服建议一直保持 false。

和其它"刷怪笼掉落"类插件同时开 break.enabled 可能会重复掉落，请二选一。

1.21.4 及以前没有 1.21.5 重构后的那套 API，插件会在启动日志里提示内部 API 不可用并自动关掉相关功能，不会崩服。

Console 里看到多个经验球是正常的：原版会把 15~44 点经验按规则拆成 1~3 个球（比如 27 点拆成 7+7+7+6）。
